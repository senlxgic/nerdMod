# nerdMod Weather (`weather.srldr`)

Real weather app for the DSi. Unlike the other nerdMod apps it is built with **BlocksDS** (DSWiFi in DSi
mode with WPA2 support, Mbed TLS for HTTPS with real certificate validation) in a separate CI job; the
resulting `weather.nds` is packaged as `_nds/TWiLightMenu/weather.srldr`.

* Data: Open-Meteo forecast and geocoding APIs (no key). City search uses the on-screen touch keyboard.
* Cache: `sd:/_nds/nerdMod/cache/weather/` (`weather.ini`, forecast cache). The home screen only reads this
  cache and never waits for the network.
* TLS: the root bundle is `source/cacerts.h` (generated by `tools/gencerts.py`). Verification is never disabled;
  if the DSi clock is before 2026-01-01 the app refuses with a clock error instead of skipping the date check.
* Status: CI-built; NOT real-hardware verified. See `docs/WEATHER.md`.
